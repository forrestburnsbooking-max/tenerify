# Reels media archive

Drop raw footage here and the episode pipeline (`npm run reels:episode N`) can pull
from it automatically. Everything in this folder is gitignored (stays local, never
deployed), so shoot freely — size doesn't matter for the repo.

## Folders — what goes where

- `broll/` — real Tenerife / experiences: boats, jet ski, Teide, harbour, sunsets,
  the actual tours. Atmosphere + payoff shots.
- `screens/` — screen recordings of the **real product**: the AI chat working, the
  booking flow, Stripe checkout, the Telegram booking alert, the admin/catalogue,
  even the terminal while coding. These replace my hand-drawn mock UI with the real
  thing = way more legit.
- `face/` — you: at the laptop, walking, on a boat, talking to camera. Even silent
  b-roll of you is gold for a founder story.
- `music/` — optional music beds (mp3). Kept low under the voiceover.

## How to shoot (so it just works)

- **Vertical 9:16** if you can (phone held upright). Horizontal is usable too — I'll
  blur-fill the sides — but vertical looks best.
- Keep clips **short, one action each** (3–10s). Many short clips > one long one.
- Steady-ish, good light. Multiple angles of the same thing = more cuts for me.
- Format: `.mp4` or `.mov`. Name them however — a hint in the name helps, e.g.
  `broll-jetski-01.mp4`, `screens-chat-booking.mp4`, `face-laptop-night.mp4`.

## Priority shot list (most useful first)

1. **Screen recording of the live chat** making a real recommendation → booking → Stripe.
2. **You at the laptop / terminal** coding (even 5–10s loops).
3. **Real Tenerife b-roll**: a boat leaving the harbour, jet ski spray, Teide, a sunset.
4. **The Telegram booking alert** popping on your phone (proof it really sells).
5. **You talking to camera** — a line or two, natural. (Even without audio, for cutaways.)
